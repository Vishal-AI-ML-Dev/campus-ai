# 7. Privacy and observability notes

## Never in telemetry (R1, R2, R5)

Prompts, questions, answers, transcripts, resumes, job descriptions, interview plans, reports, provider error
messages, audio, video, images, credentials, tokens, cookies, request bodies, query strings.

## What each system receives

| System | Interview data received | Enforced by |
|---|---|---|
| Langfuse | **Nothing** from interview steps (no callback, detached from parents) | `ai-worker/interview/no_tracing.py`; tests `test_interview_no_langfuse.py` |
| LangSmith | Nothing (forced off for interview calls and graph runs, whatever the env says) | same |
| Sentry (both services) | Exception types, stack frames (code only), method, path, request/invocation ids, environment, release | `include_local_variables=False`, `max_request_body_size="never"`, allow-list scrubbers, AI integrations disabled (`disabled_integrations`); tests `test_sentry_privacy.py`, `test_sentry_ai_integrations.py` |
| Logs (JSON) | Request id, invocation id, method, path, status, timings, error classes | Code review + sentinel tests |
| Prometheus | Aggregates with step/outcome/provider/model labels only | `test_metrics_token.py`, `test_interview_usage.py` |
| Usage ledger (`ai_usage_events`) | Ids, counts, outcome, error class, latency, tokens, cost | `ai_usage.build_event` allow-list; `test_ai_usage_ledger.py` sentinel scan |
| Admin API / Ops page | Counts, statuses, timings, diagnostics timeline | Query layer never selects content columns; `test_mock_interview_admin.py` sentinel scan |
| Alerts / webhook | Fixed messages, step, institute id, percentages | `ai_alerts.py` |

The worker's in-process `TokenCounter` callback (Phase 7.2) reads provider usage numbers and keeps no text; it is
the only callback interview LLM calls carry.

## Correlation ids

- `X-Request-ID` (validated: 1–64 of `[A-Za-z0-9._-]`, at least one letter/digit; otherwise replaced) is
  echoed to clients and propagated to the worker.
- `X-AI-Invocation-ID` is generated by the backend per worker call (stable across its connect retry), never
  returned to browsers, stored as the ledger `event_id`.
- Neither is derived from content.

## Other worker features

Mentor, resume and proof-scoring calls keep their existing Langfuse tracing when keys are set and do not yet
send correlation headers. Resume drafting prompts contain resume text — a separate privacy decision is open.
